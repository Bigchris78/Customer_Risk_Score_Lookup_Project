# Customer Risk Score Lookup

## Project Overview

This project demonstrates how Microsoft Excel can be used to combine customer information with risk ratings using XLOOKUP. The project simulates a banking environment where customer risk scores are maintained in a separate table and merged with customer records for reporting and analysis.

The project highlights Excel skills commonly used in Fraud, AML/KYC, Risk, Compliance, and Operations Analyst roles.

---

## Business Problem

Financial institutions often store customer information and risk ratings in separate systems. Analysts need to combine these datasets to identify high-risk customers and support risk monitoring.

This project uses XLOOKUP to automatically retrieve each customer's risk score and summarizes the results with Pivot Tables and charts.
